# Evidencias

Capturas y videos que prueban que el sistema funciona (lineamientos IV-c7, IX-e y 5.4-3): pruebas en Android, web y escritorio, prueba de falla y seguridad.

## Cómo se nombran

`AAAA-MM-DD_issue-N_plataforma_que-muestra.png`

Ejemplo: `2026-11-27_issue-25_n3_nuevo-primario.png`, `2026-12-01_issue-50_android_login.png`

Plataformas: `android`, `web`, `escritorio`, `n1` a `n4` (nodos), `general`.

## Reglas

- Una carpeta por issue cuando haya varias capturas: `issue-50/`.
- Videos de más de 20 MB no se suben al repo: súbelos al Drive del equipo y deja aquí el enlace en `videos.md`.
- **Prohibido:** contraseñas, tokens, IPs públicas reales ni datos personales en las capturas. Tápalos antes de subirlas.
- Cada evidencia llega en el PR del issue que demuestra, y se enlaza desde el documento correspondiente (`docs/bd/`, `docs/seguridad/`).
